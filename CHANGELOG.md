### Fixes

- **restore:** return to the session used last after a restart
- **colours:** answer OSC 10 and 11 with the attached terminal's own colours
- **session:** switch-client -l with no history goes to the session used last
- **protocol:** leave colours out of the hello when the terminal gave none
- **model:** hide scratchpads on every window teardown, never keep dead ones
- **dispatch:** scratchpads in tiny or huge windows, and menu labels with #
- **pane:** show remain-on-exit-format on a dead pane, as tmux does
- **resume:** resolve against the PATH a pane was spawned with, not its environ read back
- **cli:** a server that exits as a command connects means no server running
- **mouse:** a dragged tiled pane snaps into the grid and never floats
- **agents:** review fixes: agent-changed hook, resume PATH, hello key order, OSC app kind
- **agents:** carry the kind in agent-changed for removed records
- **agents:** quote the grofe path in claude hooks and replace stale entries on setup
- **ui:** picker times tick, detach closes picker and key menu, key menu ranks by description and ignores the prefix key
- **notify:** keep agent status formats static, wake once when a timed mute ends
- **agents:** wire surface config, detach cleanup, grid ticks, kind worktree, reporter binding; safer setup
- **agents:** double every hash before a bracket when sanitising agent text
- **agents:** forward --blocked in hook mode
- **agents:** bound hook stdin read to 200 ms on a helper thread
- **agents:** treat unknown focus as focused when focus-events is off
- **agents:** opencode setup --remove unlinks a symlinked plugin too
