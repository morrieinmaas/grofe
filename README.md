# grofe

A tmux-shaped terminal multiplexer in Rust. Familiar on the surface, correct
underneath: tmux's object model, keys and CLI verbs; a typed TOML config with
provenance; no subprocesses in the status line; pane identity and resume
commands that survive reboot.

**Status: design.** Nothing built yet.
