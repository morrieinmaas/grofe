# Security

grofe runs a server that holds your live terminal sessions, so security
problems matter.

## Reporting a vulnerability

Please report it privately through GitHub's security advisories:
[report a vulnerability](https://github.com/termage/grofe/security/advisories/new).
Do not open a public issue for it.

Include the grofe version (`grofe -V`), your OS, and the steps or a proof of
concept that shows the problem. You will get a reply in the advisory, and a
fix is released before the details are made public.

## Supported versions

grofe is an early preview. Fixes go into the latest release and `main`.
