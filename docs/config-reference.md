# Config reference

grofe reads TOML in layers: built-in defaults, `config.toml`, `conf.d/*.toml`
in lexical order, then `user.toml`. Later layers win. Every option below is a
top-level or dotted TOML key (`status.lines` is `lines` inside `[status]`).
Values keep tmux's meaning, so a tmux option maps to the key in the last
column; `import-tmux` and the `tmux` shim use the same table.

The tables are generated from the options table in `src/config/mod.rs` by
`tests/docs_config_reference.rs`, which fails when this page is stale.
After changing an option, run
`GROFE_BLESS_DOCS=1 cargo test --test docs_config_reference` and commit the result.

Beyond these options, a config file can hold `[[bind]]` key bindings, hooks,
`[plugins.<name>]` tables, `[agents]` and `[notify]`; see the README,
`docs/layouts.md` and `docs/agents.md`.

## `show-config --explain`

`grofe show-config` needs no server. It loads every layer and prints the
resolved settings. Give it a setting's name and `--explain` and it also says
which layer and file set the value:

```console
$ grofe show-config status.right --explain
status.right = "#{session_name} #{host_short}"
  set by ~/.config/grofe/user.toml
```

A value nobody set reports the built-in defaults as its source.
`grofe reload` runs the same load first, so an error in any file (with its
file, line and key) changes nothing.

## `reboot-check`

`grofe reboot-check [--json]` reads the snapshot on disk, not the server's
memory, and gives every pane a verdict: `will resume` (it has a resume
command that is saved), `restores as a shell`, or a reason it will not come
back as expected (for example a resume set a moment ago that is not saved
yet). With `--json` it prints one object per pane with `target`, `uid` and
`verdict`.

The exit status says whether the reboot is safe: `0` when every pane that
expects a resume will get it, `1` when some will not, `2` when persistence is
misconfigured (restore off and no login unit that restores, or an unwritable
state directory). With no server it prints a message and exits `0`.
