grofe

A terminal multiplexer for people who like tmux and are tired of working around it.

Read the docs Install GitHub

Survives a reboot

Panes come back in the same layout and folders, and programs that know how to resume come back running.

A config you can debug

TOML with a schema. A typo names the file and line, and show-config --explain says where a value came from.

Speaks tmux

tmux's keys, commands and formats. Your tmux plugins and scripts keep working, and grofe can run as tmux.

Framed, movable panes

Drag a pane by its title to swap or dock it, or float it above the others.

Coding agents built in

See which agent is working, which is waiting on you, and jump straight to it.

A status line that never forks

#() commands run on a timer and are cached, so redraws stay instant.

Install

Prebuilt binaries for macOS and Linux are on the releases page. Or build from a checkout with Rust 1.88 or newer:

cargo install --locked --path .
grofe
